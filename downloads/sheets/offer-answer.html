Offer, answer, and SDP

  • RFC 3264 defines an offer/answer model that uses SDP.
  • RFC 4566's page says that RFC is now obsolete and points to RFC 8866.
  • RFC 8866 opened as SDP: Session Description Protocol.
  • The offer is where codecs are proposed. The answer picks from that offer.
  • This lab does not claim a vendor's default codec.
