Three ways to put Contact Center in an app

  • Smart Embed places the agent UI in a web app, with little code, for internal tools.
  • The Contact Center SDK is for a branded UI, including chat, video, or scheduled callbacks.
  • Zoom Apps for Contact Center run inside the Zoom desktop app.
  • The page suggests Zoom Apps for agent tools such as a knowledge assistant.
  • These three options are not the same object as Zoom Phone Smart Embed.
