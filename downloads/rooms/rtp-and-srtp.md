# RTP, SRTP, and delay words

Study notes. Not vendor documentation and not legal advice.

- RFC 3550 is RTP, a transport protocol for real-time applications.
- RFC 3711 is SRTP, the secure real-time transport protocol.
- ITU-T G.711 is pulse code modulation of voice frequencies. The in-force version on the page is dated 11/88.
- ITU-T G.114 is one-way transmission time. The page lists an appendix on one-way delay for Voice over IP.
- The millisecond planning figure people remember was not printed on the G.114 page that opened. Confirm it.

Three sticky notes: RTP (RFC 3550), SRTP (RFC 3711), G.711 (ITU-T). Add G.114 with the words one-way transmission time and a confirm sticker for any millisecond number.
