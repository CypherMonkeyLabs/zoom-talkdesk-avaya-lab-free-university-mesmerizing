# Zoom Virtual Agent, and the license line

Study notes. Not vendor documentation and not legal advice.

- The Virtual Agent developer guide shows an SDK for web, Android, and iOS.
- Users can chat with the agent from a web page or a mobile device.
- The guide lists actions such as open, close, send messages, or hide a modal.
- Android and iOS SDKs require a Zoom Virtual Agent license, on the page that opened.
- A license price is not on that page.

A mobile app wants the virtual agent. Write license required, because the page says so for Android and iOS. A web modal wants open and close. Write those verbs from the guide. Leave price as confirm.
