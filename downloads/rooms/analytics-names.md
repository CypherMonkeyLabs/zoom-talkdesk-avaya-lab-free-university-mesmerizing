# Analytics names, not fake charts

Study notes. Not vendor documentation and not legal advice.

- Zoom's Contact Center navigation lists CX Insights and Analytics and reporting as labels on the product page.
- Avaya's line says measure AI, agent, and customer outcomes.
- Talkdesk's forecast API talks about queues and intervals, which is planning data, not a wallboard.
- No page opened here published a service-level percentage.
- A chart in this lab counts names and pages. It does not invent a KPI.

Build a bar for each name you saw: CX Insights, Quality Management, Workforce Management, AI Insights. The bar length is 1, meaning the name exists on a page. The axis says names, not percent.
