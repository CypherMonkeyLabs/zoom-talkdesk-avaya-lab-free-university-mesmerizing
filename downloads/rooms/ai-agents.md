# AI agents across three vendors

Study notes. Not vendor documentation and not legal advice.

- Zoom Virtual Agent has a developer SDK for chat on web, Android, and iOS.
- Android and iOS need a Zoom Virtual Agent license, on that guide.
- Zoom's API navigation lists AI Companion (retired).
- Avaya's Tandem Care line says humans and AI work together with shared context.
- Talkdesk's home title includes AI customer experience automation. The docs index does not, in the lines read, define an agent runtime.

Three cards: Zoom Virtual Agent (SDK plus a license sentence), Avaya Tandem Care (shared context), Talkdesk (title line only). Add AI Companion (retired) as a Zoom naming caution.
