# Zoom Phone developer paths

Study notes. Not vendor documentation and not legal advice.

- The Zoom Phone developer page is written for admins who set up Zoom Phone and for developers who build apps.
- It names three integration options: APIs and webhooks, Smart Embed, and Zoom Apps for Phone.
- APIs and webhooks are described for programmatic access and real-time events.
- Smart Embed places a Zoom Phone widget in a web application.
- Zoom Apps for Phone run inside the Zoom desktop client.

A CRM team wants click-to-call. Write which of the three options you are choosing and why, using only the descriptions on the developer page. Then write the word confirm next to any port, codec, or license count you have not opened.
