# Publishing

The site is the repository root. Links are relative, so the same files work at:

https://cyphermonkeylabs.com/zoom-talkdesk-avaya-lab-free-university-mesmerizing/

The sibling UC lab publishes GitHub Pages from the `main` branch, path `/`. This repository can use that same branch source. `.github/workflows/pages.yml` is the GitHub Actions path if Pages is set to deploy from a workflow instead.

Do not add a CNAME file. The organization already serves project sites on the cyphermonkeylabs.com path.
